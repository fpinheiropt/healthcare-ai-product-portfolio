# Product Management Frameworks

## 📚 Framework Library
Collection of product management frameworks and methodologies I've learned and applied in healthcare AI product development.

## 🔍 Frameworks

### 1. RICE Scoring
**Purpose**: Prioritize features and initiatives  
**Application**: Used to prioritize AI model features for HeartGuide AI  
**Resources**:
- [RICE Scoring by Intercom](https://www.intercom.com/blog/rice-simple-prioritization-for-product-managers/)
- [RICE Calculator Template](https://www.productboard.com/rice-scoring/)

### 2. Jobs to be Done (JTBD)
**Purpose**: Understand user needs  
**Application**: Applied in user research for asthma management solution  
**Resources**:
- [Jobs to be Done: A Framework for Customer Needs](https://hbr.org/2016/09/know-your-customers-jobs-to-be-done)
- [The Jobs to be Done Playbook](https://www.strategyzer.com/books/jobs-to-be-done-playbook)

### 3. HEART Framework
**Purpose**: Measure product success  
**Application**: Defining success metrics for GlucoWise AI  
**Metrics**:
- **Happiness**: User satisfaction scores
- **Engagement**: Daily active users
- **Adoption**: New user signups
- **Retention**: 30-day retention rate
- **Task Success**: Prediction accuracy

### 4. Kano Model
**Purpose**: Feature prioritization  
**Application**: Categorizing features for MVP development  
**Categories**:
- **Must-haves**: Core prediction functionality
- **Performance**: Prediction accuracy
- **Delighters**: Personalized health insights
