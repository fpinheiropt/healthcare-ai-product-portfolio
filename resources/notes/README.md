## 🧠 AI/ML in Healthcare

### 1. Key Concepts
- **Transfer Learning in Medical Imaging**
  - Pre-trained models (e.g., ResNet, DenseNet) can be fine-tuned with medical images
  - Challenges: Limited labeled data, class imbalance, domain shift
  
- **Federated Learning**
  - Enables model training across multiple institutions without sharing raw data
  - Applications: Medical imaging, clinical NLP, drug discovery

### 2. Regulatory Considerations
- **FDA AI/ML-Based Software as a Medical Device (SaMD)**
  - Predetermined Change Control Plan (PCCP)
  - Good Machine Learning Practices (GMLP)
  - Real-World Performance (RWP) monitoring
